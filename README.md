# 安全岛 · Sanctuary

一个以实时 3D 森林为场景的放松网页，包含呼吸引导、环境音播放和小动物互动。

鼠标滚轮向上放大、向下缩小，镜头在 88%～118% 范围内平滑变化。按住鼠标中键（滚轮键）拖动可小范围调整视角，松开后保留位置。双击森林画面可平滑恢复默认视角和缩放。

鼠标划过草地会产生轻柔的局部风动：划动越快、连续幅度越大，草叶弯动越明显、影响范围越宽；停下后逐渐恢复。

按住鼠标左键在草地上拖动，可画出草叶轻轻伏低、带少量微光的小径。松开后，离小径起点最近的小动物会先走到起点，再沿路线行走；走过的草叶和微光逐渐恢复。同时最多保留三条小径，开始绘制第四条时，最早的一条会用约三秒淡出，微光逐渐消散，草叶平滑恢复。同一只动物被新路线选中时会转向新路线，旧路线渐渐消散。单击动物仍可触发爱心互动。

## 运行

```sh
npm install
npm run dev -- --port 5173
```

打开 http://127.0.0.1:5173/ 。

```sh
npm run check
npm test
npm run build
npm run preview -- --port 4173
```

## 可编辑文件

- `index.html`：标题、入口、呼吸光球、播放器的 HTML。
- `src/styles.css`：字体、玻璃效果、手机与桌面布局。
- `src/scene.js`：实时 Three.js 森林、风动草叶、狐狸/兔子/猫、点击爱心、光束与粒子。
- `src/audio.js`：森林音频、渐入渐出、备用环境音和柔和的合成音层。
- `src/main.js`：入场、播放暂停、呼吸周期、指针视差、窗口自适应与渲染循环。
- `src/interactions.js`：滚轮缩放、中键视角调整、鼠标在草地上的定位与局部风力变化。
- `src/trail.js`：路线平滑、选择最近的动物、沿路行走和小径恢复。
- `src/trail-effects.js`：左键绘制、草叶压低和稀疏微光。
- `public/sites/safe-island/forest-stream.mp3`：森林环境音频。

## 技术与部署

使用 Three.js 构建实时森林场景，GSAP 实现场景与界面过渡，Vite 提供开发服务与生产构建。

场景、音频与交互逻辑拆分为 ES 模块，依赖通过 npm 管理。

字体使用 Google Fonts（Cormorant Garamond、Noto Serif SC、Inter），需要网络；3D 依赖与音频均由本地提供。

森林布局、动物行动、粒子由随机数与时间驱动，所以不同刷新之间的具体位置不会完全相同。

如需部署到某个子路径，应设置 Vite 的 `base` 并同步调整音频路径。
